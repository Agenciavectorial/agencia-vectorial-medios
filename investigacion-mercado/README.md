# Investigación de mercado — Prospectos Medellín (nov 2026)

Base de datos de **700 negocios de Medellín** sacada de Google Maps (vía Apify) en los 14 nichos donde ya tenemos casos reales para mostrar, con su número de WhatsApp, lo que le falta a cada uno y qué ofrecerle.

| Archivo | Para qué |
|---|---|
| `prospectos-medellin-2026-11.xlsx` | Base principal. Hojas: **Contactar ya (A)**, Base completa, Resumen por nicho, Guiones WhatsApp, Metodología |
| `prospectos-medellin-2026-11.csv` | La misma base completa, para importar en un CRM o herramienta de WhatsApp |

## Números clave
- 700 negocios · **504 con celular (WhatsApp probable)** con link `wa.me` directo
- **408 sin página web propia** (292 sin web + 108 que solo enlazan a Instagram/Facebook/link en bio)
- **153 con la ficha de Google sin reclamar** → venta directa del servicio de Ficha de Google ($250.000)
- **103 prospectos prioridad A** (puntaje alto + WhatsApp)
- 20 cadenas/negocios grandes descartados

## Cada fila trae
WhatsApp · teléfono · lo que le falta · qué ofrecer (con precio) · caso del portafolio a mostrar · **mensaje de WhatsApp ya personalizado** · estado de la web · Instagram (seguidores, días sin publicar) · calificación, reseñas y fotos de la ficha · barrio y dirección · link a Google Maps · columna **Estado** (lista desplegable para el seguimiento).

## Cómo usarla
1. Empieza por la hoja **Contactar ya (A)**, nicho por nicho (es más fácil mostrar el caso del mismo gremio).
2. Revisa la ficha antes de escribir (link Google Maps) y ajusta el mensaje sugerido.
3. 15–20 mensajes al día, personalizados, para que WhatsApp no marque el número como spam.
4. Marca el **Estado** y haz seguimiento a las 48 h (guion en la hoja *Guiones WhatsApp*).
